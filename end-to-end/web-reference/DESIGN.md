# Recording workbench

One compact customer reference app. Warm paper, ink/teal typography and a coral
action accent. Serif headings and monospace metadata distinguish content from
controls. Responsive list/detail panes, plain CSS and local fonts; no private
component package or third-party asset service.

Keep every feature in its own short file. Label demo fixtures clearly. Render
untrusted transcript/summary/Ask strings as text. Preserve visible focus,
keyboard actions, loading/empty/error states and narrow-screen navigation.
Never expose API credentials or internal journal/error details in product UI.
